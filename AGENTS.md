# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

CDK construct library for provisioning Turso cloud databases. Built with projen's `AwsCdkConstructLibrary` template, using JSII for potential multi-language support (Python, Java, C#, Go).

## Commands

```bash
npm run build          # Full pipeline: compile → test → package
npm run compile        # jsii compiler (TypeScript → JS + .d.ts)
npm run test           # Jest (with coverage) + ESLint
npm run test:watch     # Jest in watch mode
npm run eslint         # ESLint with --fix on src/, test/, projenrc/
npm run watch          # jsii in watch mode (for development)
npx projen             # Regenerate project files from .projenrc.ts
```

Run a single test file: `npx jest --passWithNoTests test/hello.test.ts`

## Projen: Critical Rule

Most configuration files are **generated by projen** and must NOT be edited directly. This includes `package.json`, `.eslintrc.json`, `tsconfig.dev.json`, GitHub workflows, and anything marked with `~~ Generated by projen`. To change project configuration, edit `.projenrc.ts` and run `npx projen`.

## Architecture

- **Source**: `src/` — construct classes exported from `src/index.ts`
- **Tests**: `test/` — Jest tests (`*.test.ts`)
- **Compiled output**: `lib/` (generated, gitignored)
- **Distribution**: `dist/` (generated, gitignored)
- Peer dependencies: `aws-cdk-lib` (^2.1.0), `constructs` (^10.0.5)

## Code Style (enforced by ESLint)

- 2-space indentation, single quotes, semicolons required
- 150-char max line length
- Member ordering: public → protected → private; static → instance
- Import ordering: builtin → external, alphabetized
- Strict TypeScript: `noImplicitAny`, `strictNullChecks`, target ES2020
